# Team portraits

Drop the two real photographs here to replace the elegant placeholder busts.
The filenames must match the `photo` paths in `src/lib/site.ts`:

| Person          | Expected file                     |
| --------------- | --------------------------------- |
| Renato Marques  | `/public/team/renato-marques.jpg` |
| (Your portrait) | `/public/team/director.jpg`       |

Recommended: portrait orientation, at least 800×1000px, face centered and
toward the top of the frame (images are cropped with `object-top`).

Until a file exists at the expected path, the site automatically shows a
drawn placeholder bust with the person's initials and a "Portrait to follow"
caption — no stranger's face is ever shown under a real name.
